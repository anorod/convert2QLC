# 10 - Frontend - API Integration

**Description**
Implement the logic to communicate with the backend API. This includes creating a service to handle the API calls, sending the file to the backend, and handling the success and error responses.

**Checklist of acceptance criteria**

* [ ] Create a service to handle API requests to the backend.
* [ ] Implement the logic to send the uploaded file to the `/api/v1/convert` endpoint.
* [ ] Handle the JSON response from the backend on success.
* [ ] Handle the JSON error response from the backend.
* [ ] Display the conversion summary and error messages in the UI.
