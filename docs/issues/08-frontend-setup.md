# 08 - Frontend - Initial Setup

**Description**
Initialize the frontend project using a modern JavaScript framework like Vue.js or React. This includes setting up the basic project structure, dependencies, and a simple component to ensure the development environment is working correctly.

**Checklist of acceptance criteria**

* [ ] Initialize a new Vue.js or React project.
* [ ] Create the basic folder structure for components, services, and styles.
* [ ] Create a simple "Hello World" component to verify the setup.
* [ ] Configure the development server.
