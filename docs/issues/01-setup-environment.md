# Setup Initial Project Environment

**Description**
This task involves setting up the foundational structure of the project, including the Git repository, directory layout, and initial Docker configuration. This will ensure all developers have a consistent environment to start working from.

**Checklist of acceptance criteria**

*   [ ] The project is initialized as a Git repository.
*   [ ] The base directory structure (`/backend`, `/frontend`, `/docs`) is created.
*   [ ] A basic `docker-compose.yml` file is created, defining the `backend` and `frontend` services.
*   [ ] A placeholder `Dockerfile` exists inside the `/backend` directory.
*   [ ] A placeholder `Dockerfile` exists inside the `/frontend` directory.
