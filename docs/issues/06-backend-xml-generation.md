# 06 - Backend - XML Generation

**Description**
Implement the logic to generate the QLC+ XML file (`.qxc`) from the parsed Picolo show data. This involves creating the base XML structure, a generic fixture, scenes for each cue, and a chaser to sequence the scenes.

**Checklist of acceptance criteria**

* [ ] Create the base structure of the QLC+ XML document.
* [ ] Implement the generation of a generic fixture based on the highest channel number.
* [ ] Implement the generation of a scene for each cue, including channel levels.
* [ ] Implement the generation of a chaser that includes all the scenes in the correct order.
* [ ] Ensure the generated XML is well-formed and valid according to the QLC+ format.

> Tags: backend, xml, qlc+
