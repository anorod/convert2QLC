# 07 - Backend - API Endpoint

**Description**
Create the FastAPI endpoint to handle the conversion requests. This includes setting up the FastAPI application, creating the `/api/v1/convert` endpoint, and handling file uploads.

**Checklist of acceptance criteria**

* [ ] Set up the basic FastAPI application.
* [ ] Create the `POST /api/v1/convert` endpoint.
* [ ] Implement file upload handling using `multipart/form-data`.
* [ ] Integrate the conversion logic with the endpoint.
* [ ] Implement the JSON response format for success and error cases.
