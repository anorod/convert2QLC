# 09 - Frontend - UI Design and Layout

**Description**
Design and implement the main user interface for the application. This includes creating the file upload form, the conversion button, and the area where the results will be displayed. The design should be clean, intuitive, and user-friendly.

**Checklist of acceptance criteria**

* [ ] Design a simple and intuitive layout for the main page.
* [ ] Implement the file upload form with a "Convert" button.
* [ ] Create a section to display the conversion results (summary and download button).
* [ ] Implement a loading indicator (e.g., spinner) to show when the conversion is in progress.
* [ ] Implement a section to display error messages.
