# 11 - Frontend - File Handling

**Description**
Implement the file handling logic in the frontend. This includes client-side validation of the file before uploading, and the logic to download the converted `.qxc` file.

**Checklist of acceptance criteria**

* [ ] Implement client-side validation for the file extension (`.txt`).
* [ ] Implement client-side validation for the file size.
* [ ] Implement the logic to generate and download the `.qxc` file from the `fileContent` received from the API.
* [ ] Implement server-side validation in the frontend before sending the file to the backend.
