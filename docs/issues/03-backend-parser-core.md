# Implement Picolo File Parser

**Description**
Develop the core logic for parsing the input `.txt` file from the Picolo console. This module will read the file content and transform it into structured Python objects representing the Cue List, channel levels per cue, and the maximum channel number.

**Checklist of acceptance criteria**

*   [ ] A `parser.py` module is created.
*   [ ] The module can correctly parse the "Cue List" section into a list of data objects.
*   [ ] The module can correctly parse the "Cues content" section into a dictionary mapping Cue numbers to channel data.
*   [ ] The module correctly identifies and stores the highest channel number found in the file.
*   [ ] Unit tests are created to validate the parsing logic with a sample Picolo file.
