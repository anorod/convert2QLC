# Configure Backend Testing Framework

**Description**
Set up the testing environment for the Python backend. This includes choosing and installing a test runner (like `pytest`) and establishing the structure for unit tests. This foundation is critical for developing tests alongside new features.

**Checklist of acceptance criteria**

*   [ ] A testing framework (`pytest` is recommended) is added to the backend's dependencies.
*   [ ] The `/backend/src/tests/` directory is created and configured to be recognized by the test runner.
*   [ ] A sample test case is created to verify that the test runner is working correctly.
*   [ ] The `docker-compose.yml` file includes a command or instruction on how to run the tests within the container.
