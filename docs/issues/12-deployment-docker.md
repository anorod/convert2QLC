# 12 - Deployment - Docker

**Description**
Finalize the Docker configuration for a production environment. This includes optimizing the `Dockerfile`s for both the backend and frontend, and configuring `docker-compose.yml` for production use.

**Checklist of acceptance criteria**

* [ ] Optimize the backend `Dockerfile` for production (e.g., using Gunicorn).
* [ ] Optimize the frontend `Dockerfile` for production (e.g., multi-stage build with Nginx).
* [ ] Configure `docker-compose.yml` for a production environment.
* [ ] Configure Docker volumes for persistent logging.
